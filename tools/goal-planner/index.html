⚙️ How the Goal Planner Works

The Goal Planner is a direct lookup tool — no scoring, no algorithm. Each goal is a hand-curated progression path pulled from our guide pages:

  1. Search or browse — Type any item, boss, or milestone name, or click a category tab to filter.
  2. Select a goal — Click on a goal from the dropdown or card list.
  3. Follow the path — Each result shows the exact materials needed, which NPCs to rescue first, required Flame Altar level, minimum player level, location info, and a numbered step-by-step checklist.

Every result includes links to our detailed guide pages for deeper information. Material quantities are derived from in-game crafting tiers — entries marked "estimated" haven't been verified against exact game data yet.
